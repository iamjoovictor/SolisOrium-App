# Stack: React Web (Vite), Mobile First

Este projeto NÃO usa mais Expo/React Native. É uma SPA React pura, construída com Vite.

- Roteamento: `react-router-dom`
- Estilo: Tailwind CSS — sempre escreva classes mobile-first (sem prefixo = mobile; use `md:`/`lg:` para telas maiores)
- Ícones: `react-icons/io5` (Ionicons)
- Mapa (tela Recarga): `@react-google-maps/api`, requer `VITE_GOOGLE_MAPS_API_KEY` em `.env`
